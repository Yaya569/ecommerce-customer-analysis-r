# E-commerce Customer Analysis in R

## Project Overview

This project explores customer purchase behaviour using R, with a focus on data cleaning, customer segmentation, exploratory analysis and business insights.

The analysis examines customer characteristics, purchasing behaviour and spending patterns across different demographic groups and countries.

The project demonstrates how raw customer transaction data can be transformed into meaningful insights through data preparation, aggregation, visualisation and statistical analysis.

## Dataset

The dataset contains customer purchase information, including:

- Customer ID
- Age
- Gender
- Purchase Amount
- In-Cart Amount
- Country

Additional variables were created during the analysis, including customer age groups and total payable amount.

## Data Cleaning

The analysis includes several data preparation steps:

- Identifying missing values
- Handling missing gender values
- Creating customer age groups
- Creating a total payable variable
- Checking the structure and quality of the dataset

## Customer Analysis

The analysis investigates:

- Average purchase amount by gender
- Total in-cart amount by age group
- Customers with the highest total payable amounts
- Differences in purchasing behaviour across countries
- The proportion of customers whose in-cart amount is close to their purchase amount

## Key Findings

The analysis identifies differences in purchasing behaviour across customer groups and countries.

Key areas explored include:

- Purchasing behaviour by gender
- Spending patterns across age groups
- High-value customers
- Differences in purchase amounts between countries
- Customer spending patterns based on purchase and in-cart amounts

## Visualisation

Base R was used to visualise purchase behaviour across countries.

A boxplot was created to compare the distribution of purchase amounts between countries and identify differences in central tendency, variation and potential outliers.

## Statistical Analysis

The project also considers statistical methods for evaluating whether purchasing behaviour differs across demographic and geographic groups.

The analysis focuses on comparing purchase amounts across gender and country groups while considering the assumptions and limitations of statistical testing.
